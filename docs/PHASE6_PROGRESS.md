## 新入口

工作台「研究工具」→「进入完整研究工作区」，或同一站点 `/workspace`。按图表与结构、版本与管理、全文翻译、工具 Agent、检索与追踪、图谱与综述、后台任务分类。原问答与比较入口保留。阅读页增加本页研究工具和中英对照。

当前回答允许小型 Markdown 表格；前端只渲染经过转义的文本单元格，拒绝模型 HTML。结构化表格保留未知值和合并范围，不复制缺失实验值。CSV 防公式注入。图表脚本由固定程序生成，不运行模型代码。

## 反馈修订：主界面批量导入（2026-11-16）

- 「导入资料」新增「单篇导入 / 批量导入」切换；支持多选、拖入、待上传队列、移除、清空和统一备注。多文件拖到原单篇入口时也会转入批量队列。
- 每批最多 20 个 PDF、合计 50 MiB，前后端均检查总量。选择文件后需点击「开始批量导入」，上传期间显示实际传输进度。
- 逐篇显示解析进度、成功、重复、版本待确认、取消和失败结果；相同文件不重复入库，关联版本由用户逐篇选择保留或取消。
- 成功的新论文保存本批备注；重复文件保留已有备注。个别损坏文件不阻止其余文件；临时失败任务支持跳过已完成文件继续处理。
- 刷新后恢复最近批次，可查看历史批量任务。暂存文件与任务恢复仍依赖服务磁盘保留，不承诺免费 Render 重启后持久化。
- 本次没有接入视觉模型。公式候选仍是 PDF 提取的原文及位置，尚未可靠转写为 LaTeX；图表截图不等于图片语义理解。
