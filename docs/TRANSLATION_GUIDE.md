# 阅读翻译与批量翻译使用、测试说明

更新：2026-11-18。

## 现在怎么操作

### 阅读一篇论文

1. 在论文库点“查看”，进入论文阅读页，选择需要阅读的原始页码。
2. 点击“段落与本页翻译 ↓”，滚动到阅读区下方。上方原论文、页码和章节导航仍然保留。
3. 段落翻译：在右侧“本页文字”中选中连续原文，原文会自动填入下方输入框；选择语言，点“翻译段落”。也可粘贴本页连续原文，最多 8000 字符。段落结果只在当前页面展示。
4. 整页翻译：点“翻译当前整页并保存”。后台处理当前页，完成后自动显示译文；每页结果保存在服务端，可刷新后再看。
5. 点“返回原文 ↑”，回到原论文。翻页时，下方原文与已保存译文会跟随页码变化。
6. 需要处理多篇论文时，点“多篇批量翻译 ↗”。它会新开独立工具页，保留原来的阅读窗口。

以前重复的“中英对照”区域已合并；阅读页不再跳往笼统的研究工作区。当前所在工具的侧边栏项目也不会再新开一个同样的工具页面。

### 批量翻译多篇论文

入口：研究工具 → 阅读与核对 → 批量翻译。

1. 勾选需要翻译的论文，一次最多 30 篇，可搜索题名、备注等。
2. 每篇都会显示“共 N 页，可填写 1–N 页”。
3. 选择目标语言、翻译范围：
   - “每篇的指定页范围”：所有选中论文使用同一起止页。例如填 1–1，只翻每篇第一页。可填范围由所选论文中页数最少的一篇决定。
   - “每篇的全部页面”：按每篇各自的实际页数翻译。例如一篇 3 页、一篇 15 页，将分别处理 3 页与 15 页。
4. 启动前会显示论文数、页数合计。越界、空白、非整数、起始页大于结束页时，直接说明具体问题并禁用开始按钮。服务端也会在启动前检查全部论文。
5. 启动后，同一页显示任务进度和各论文的已保存页数。某篇失败时会继续尝试其他论文，已完成页会保留。
6. 未完成时点“继续未完成步骤”，成功页无需重复处理。也可在“后台任务”中继续。
7. 每篇结果都有“打开论文与译文 ↗”；已保存页面后可以“下载已保存的双语文档”（Markdown）。
8. 刷新工具页会找回最近一次批量翻译任务。该任务结果中的论文范围以任务自身列出的论文为准。

## 建议先测这四项

1. **页数提示**：选 Transformer v7，应显示共 15 页。结束页填 20，立即提示可填 1–15；开始按钮不可点击。改回 1，恢复可用。
2. **原地翻译**：阅读页第 3 页翻译当前整页；完成后仍在第 3 页，下面显示译文。点击“返回原文”可直接回阅读区域。
3. **批量试译**：选两篇论文，起止页都填 1。应生成一个批量任务，显示两篇各自的进度与结果入口。先用一页测试即可。
4. **结果复用**：完成后刷新阅读页，相同语言的整页译文仍可读取；批量结果可下载。翻到没翻译过的页面时，显示该页尚未翻译，不能沿用上一页译文。

翻译需配置可用的文字模型接口。扫描论文应先完成 OCR。这里的“页码”都是 PDF 原始页码。结果仍需与原文核对；已保存译文和任务记录依赖服务端存储保留。
