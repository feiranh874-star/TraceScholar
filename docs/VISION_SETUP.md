# 豆包视觉接口配置与第一次测试

## 先处理密钥

聊天中曾粘贴过的 API Key 应在火山方舟控制台撤销，再创建一把新密钥。新密钥只填本机 `.env`，不要发到聊天、写入文档或提交 GitHub。

代码没有使用聊天中那把密钥，也没有把它写入任何项目文件。

## 本机配置

打开项目根目录 `.env`，找到已经添加的四行。只需在 `VISION_API_KEY=` 后填写新密钥，其余保持下列设置：

```dotenv
VISION_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
VISION_MODEL=doubao-seed-2-1-pro-260915
VISION_API_KEY=
VISION_TIMEOUT_SECONDS=120
```

DeepSeek 的 `LLM_` 配置继续用于文字问答。视觉接口使用用户提供示例中的 Ark Responses 格式：`POST /responses`、`input_image` 和 `input_text`。请求把当前一页渲染为 PNG，以 data URL 发送，不需要公网 PDF 地址。

填写后重启本地后端。已有启动脚本应加载根目录 `.env`；如果手动启动，可在项目根目录执行（按实际使用的端口调整）：

```bash
cd backend
./.venv/bin/uvicorn app.main:app --env-file ../.env --port 8012
```

若端口仍被旧服务占用，先在原终端按 Control+C 停止旧服务。不要同时启动两套服务指向同一份资料。

Render 上需单独在 Environment 中设置这四个变量，填写新密钥后重新部署。代码推送不会上传本机 `.env`。

## 公式与图片

- 找到含公式的一页，执行同样的一页视觉识别。公式区域显示原图和数学公式预览；「查看 LaTeX 源码」可展开代码，「复制 LaTeX」保留转写内容。预览使用本地打包的 KaTeX 0.16.22 输出 MathML，不访问 CDN；无法排版时保留原图和代码。
- 图片结果显示原图区域及模型对可见内容的描述。模型定位可能偏移，应使用「核对完整原页」。
- 扫描 PDF 可直接进行视觉图表识别，不要求先完成 OCR；若 OCR 正在运行，请等待结束。扫描正文全文检索仍使用现有 OCR 流程。
- 每页最大边渲染至 2400 像素、图像不超过 8 MiB；极密集表格可能仍需更清晰的局部截图方案。模型结果不是人工认证，也没有自动写入正文检索索引。

## 失败时

- 密钥/权限/额度错误显示可读提示，原始服务错误体和密钥不写入任务记录。
- 网络或服务失败不自动重发模型请求，避免无意重复扣费。手动重试仍可能产生额外费用。
- 新结果若不完整或列数不齐，会被拒绝，不覆盖旧结果。仅合并范围有冲突时忽略该范围并明确提示，保留全部原始单元格文字、数字和空白，不移动或补值。
- 「后台任务」可以查看失败原因或继续中断任务。已有缓存依赖服务端磁盘，免费 Render 临时磁盘重建可能丢失。
