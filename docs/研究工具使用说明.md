# 研究工具怎么用

## 先分清三个查资料的入口

| 你想做的事 | 在哪里操作 | 会得到什么 |
| --- | --- | --- |
| 想知道哪些论文谈到某个信息 | 证据检索 → 输入概念 → 全库查找 | 按论文分组的相关正文、命中页码；每页显示 10 篇，可翻页 |
| 在一篇论文中找原文或解答问题 | 证据检索 → 选择范围 → 只检索原文 / 智能体回答 | 少量最相关的原文，或带引用的回答 |
| 对比几篇论文的方法或结论 | 证据检索 → 切换到多篇比较 → 勾选 2–30 篇 | 分别检索每篇论文后生成比较回答 |

全库查找不限制为五篇，结果每页显示 10 篇，可翻页。多篇比较已从最多 5 篇扩展为最多 30 篇，并提供“选择当前列表”和“清空勾选”。比较会为每篇论文分别检索证据并检查回答是否引用了全部所选论文；论文越多，模型调用的等待时间及费用通常越高。仅想查哪些论文提到某个信息，使用全库查找即可。

点击检索范围第一行的“收藏夹”，在悬浮窗口中选择收藏夹，例如 `12`。页面会显示“已选择：12”，再点下方论文搜索框，就只会显示这个收藏夹内的论文，按入库时间从新到旧排列；也可以继续输入题名、作者、文件名或备注筛选。窗口内支持按名称搜索收藏夹，选择“全部论文”可恢复全库范围。

选中一篇论文后，收藏夹筛选仍然保留；点“清除论文选择”会回到整个收藏夹范围。“收藏夹查找”始终查当前收藏夹；“只检索原文”和“智能体回答”使用当前选定的单篇论文或整个收藏夹。在多篇比较中，勾选列表也只显示当前收藏夹的论文。收藏夹名用于选范围，请在上方“研究问题”框填写实际要查的信息；未填写时会提示“输入不能为空”。

建议先用简短概念，例如 `attention`、`few-shot learning`、`注意力`，或问“哪些论文提到过注意力？”。目前使用正文关键词、词形和已支持的中英术语匹配，并排除已识别的参考文献区。命中说明找到相关原文线索，不等于论文支持了某个结论；请打开原页核对。任意同义改写、尚未识别的扫描页、图中未入索引的文字仍可能漏检。

每篇先显示最多三个相关片段，同时列出所有命中页码。收藏夹查找会显示所选收藏夹名和实际检索篇数。点击片段展开，再点原文链接，会在新标签页打开论文，保留检索结果。不同版本按独立入库记录展示。

## 研究工具首页：五个直接使用的小工具

| 功能 | 怎么操作 | 结果有什么用 |
| --- | --- | --- |
| 引用图谱 | 勾选相关论文，点构建图谱 | 看库内哪些论文引用了哪些论文。箭头来自真实参考文献匹配；没有匹配就不连线。PageRank 仅表示当前所选子图内的结构位置，不代表论文质量。 |
| 本地论文推荐 | 只勾选一篇作为起点，点发现相关论文 | 在现有论文库中找题名、摘要相近的文章；不会自动联网找全部论文。 |
| 有来源的研究提纲 | 勾选最多 8 篇论文，输入研究想法，点整理提纲 | 获得章节建议、真实参考文献及依据。需要初稿时再点扩写，扩写调用模型。 |
| arXiv 题名检索 | 输入题名或关键词，点检索公开论文，核对后再导入 | 找尚未入库的公开论文。需要联网，但不调用生成模型。空输入会在框下提示。 |
| CSV 图表与图注 | 上传实验 CSV，填写文件中的 X/Y 列名，选择图型 | 生成实验图、图注和可复现绘图脚本。CSV 是你提供的数据，不会自动从所有 PDF 中拼出实验数据。 |

不用把五个按钮都运行一遍。先确定自己的目标，再选相应工具。

## 完整研究工作区：七类任务

点击工具首页的任务卡，或“进入完整研究工作区”，会新开一个标签页。工作区顶部还有可展开的新手指南，每个任务上方会说明用途、步骤和模型调用情况。

**资料范围怎么选：**单篇操作看“目标论文”和 PDF 原始页码；多篇操作看上方勾选列表。这两种选择相互独立。版本比较使用该任务内的两个版本选择框。

| 任务 | 它具体做什么 | 你先做什么 |
| --- | --- | --- |
| 图表与结构 | 展示当前页原图、表格结构和 CSV；按需视觉识别；基于当前页问答；查看参考文献及正文引用上下文 | 选目标论文和原始页码。先看原图，提取不准再手动视觉识别。 |
| 版本与管理 | 比较同一篇论文两个版本的正文差异，下载报告；纠正题名、作者、摘要；重新解析；恢复归档 | 比较时选择同一论文的两个已关联版本，如 v1 / v7；修改资料时看顶部目标论文。 |
| 全文翻译 | 按页翻译并保存，查看双语内容，下载已完成内容 | 选论文、目标语言和起止页，建议先试一页。翻译调用模型。 |
| 分步研究助手 | 根据问题选择检索、查页、图谱等工具，展示执行步骤摘要和带来源的回答 | 勾选论文，写清问题，再运行。需要调用模型；执行记录不等于隐藏推理过程。 |
| 检索与追踪 | 搜索 arXiv 并导入；按间隔检查主题；本地推荐及反馈；提取原文中的代码仓库线索 | 搜新论文用题名框；跟踪主题用关键词框。追踪只在服务运行时检查，休眠或重启会影响检查时机。 |
| 图谱与综述 | 整理引用关系、Future Work 原文和时间线；生成带引用综述；查找一个研究方向的相关证据；生成可编辑方法图脚本 | 先勾选论文并填主题。证据整理不调用模型；生成综述及核对意见调用模型。它不证明全球新颖性。 |
| 后台任务 | 批量导入，查看解析、翻译、视觉识别的进度，继续失败或中断任务 | 有长任务时查看；查看记录不调用模型，继续模型任务可能继续计费。 |

“单独打开此工具”会在新标签页打开当前任务。任务标签支持 ⌘ / Ctrl + 点击新开，也支持浏览器后退和前进。目标论文与页码可随链接带过去；多篇勾选需在新页面重新确认。

## 这次可以怎么验收

1. 入库至少六篇正文包含同一术语的论文，查这个术语。确认命中数可超过五篇；超过十篇可翻页，前后页没有遗漏或重复。
2. 加一篇仅在参考文献中出现该术语的论文，确认在参考文献区已识别的情况下不会把它当正文命中。
3. 在 arXiv 检索框不填内容，直接搜索；应在框下显示“输入不能为空”，没有请求发出。提纲空输入同理。
4. 到完整工作区的版本与管理页，使用长题名。目标论文、页码、阅读入口应对齐；两个版本框应等高，保存和重新解析按钮有间距。
5. 打开一条原文来源，确认原检索页仍在；切换工作区任务后使用浏览器后退，确认回到上一任务。
6. 新建一个含六篇论文的收藏夹，点击“收藏夹”并选中它。确认显示“已选择：收藏夹名”，论文搜索框只列出这六篇；切换多篇比较，点击“选择当前列表”，应显示“比较所选论文（6）”，返回按钮显示“返回”。
