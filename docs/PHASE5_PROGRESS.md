# 第五轮开发：版本策略、真实 OCR 与六模块基础补齐

日期：2026-11-15。接续第四轮总结与比赛缺口复盘，按用户确认的顺序实施。本轮属于六模块基础版建设，不代表全部官方高级要求已经通过。

## 1. 内容去重与版本选择

- 浏览器导入时先检测关联记录，存在冲突返回选择界面，此时新文件尚未入库。
- 支持“保留原记录并取消导入”“两版都保留”“确认替换指定记录”。替换要同时核对目标记录及文件哈希，避免用过时选择操作另一条记录。
- 替换采用归档语义：旧记录退出默认论文库和检索范围，原文件及历史页码链接保留，不会直接删除旧论文。归档数据仍占存储空间；尚未提供独立归档管理/恢复界面。
- 新增正文五词片段哈希与 Jaccard 重合率，结合 arXiv/DOI 标识解释匹配依据。使用最多 20 个均匀采样页，长文档比较有抽样边界；无充足正文时不根据相似度强行关联。
- 这是可解释的近重复文本比对，不是稠密语义 embedding，不能保证识别大幅改写、跨语言或扫描噪声下的同篇论文。
- 为兼容已有 API 客户端，上传接口未指定策略时仍按保留两版处理；Web 界面明确发送 ask，用户选择后才导入。

真实样例验证：将官方 v7、v1 改为任意文件名上传，仍从正文与标识识别关联，正文重合率约 0.7236，并建议保留库中 v7。另有不含相同题名/标识的正文近重复测试、无关论文对照、过时替换目标与旧引用保留测试。

## 2. 实际 OCR、进度与恢复

- 单独启动后台 OCR，不把整本书送给大模型。Linux/Docker 用 CPU Tesseract；macOS 无 Tesseract 时可用系统 Vision（首次编译需 Xcode Command Line Tools）。
- 全站同时处理一个 OCR 任务，每页独立识别并保存；任务记录显示实际处理页数、成功页和失败页。
- 重试从已落盘页面判断哪些页仍待识别，跳过已完成页；进程重启后显示任务中断，可由用户继续。不是自动分布式持久队列，也不能恢复已被托管平台清空的临时磁盘。
- 成功页重新进入章节、文本块与检索流程，保留原 paper_id 和页码；低文字页或失败页继续明确标记，不假装全部完成。
- Dockerfile 增加 Tesseract 英文/简体中文语言包。英文默认使用 eng，可通过 OCR_LANGUAGES=eng+chi_sim 识别混合语言。macOS 默认配置英文与简体中文。

真实验证：官方 1706.03762v1_img.pdf 共 15 页，macOS Vision 实际全部识别，未记录失败页，生成 50 个文本块。检索 scaled dot product attention 返回原扫描论文第 4、3、5、8 页的候选证据。这只证明文本 OCR 与页码链路，不代表公式、表格和图形已结构化恢复；Tesseract 云端效果仍待部署后单独验证。

## 3. 原版阅读与段落翻译

- 提供受现有认证保护的原始 PDF 地址。
- 为避免浏览器 PDF 插件兼容问题，使用 PyMuPDF 按原版版式逐页渲染为图片，保留公式和图表外观；可切页、按章节选页和缩放。
- 阅读器元数据默认折叠，优先展示原文。可在分页文字中选择连续片段，或粘贴本页原文，调用现有模型做中译英/英译中。
- 服务端检查片段确实来自指定论文页面，提示模型保留代码、公式、数字和引用；文本仅作为资料处理。显示模型失败并允许重试。

真实验证：浏览器检查原版页面与章节跳页；DeepSeek 段落翻译真实返回成功。当前没有原版坐标高亮、原位文字选择、全文翻译、双向同步滚动或正文引用与 References 的完整双向跳转。

## 4. 图谱、推荐、写作与 CSV 小闭环

### 真实引用图谱

选择最多 30 篇论文，从明确的 References/Bibliography 区域匹配库内论文题名；仅为匹配成功的关系建立有向边，保留参考文献页和原文片段。计算 PageRank（阻尼系数 0.85）和库内入边数，支持点击节点、证据跳页及下载 JSON。

真实四文档实验：Transformer、Layer Normalization、CLIP、GPT-3 共找到 4 条引用边。自动化测试确保只在正文提及题名时不生成引用边。尚未建立大规模书目消歧算法、Future Work 最新进展查证或领域级影响力评价；部分缺失引用边可能是抽取/题名匹配漏检。

### 可解释推荐与公开论文导入

本地推荐采用题名/摘要 TF-IDF 余弦相似度，排除同 work_id 的不同版本，返回共同术语和得分；没有内容依据时不强行推荐。

新增 arXiv 题名检索与确认导入，通过固定 HTTPS 接口获取公开论文，限制文件大小并拒绝任意 URL/重定向。外部失败不影响本地问答。已修复把题名停用词作为强制条件导致返回空结果的问题，精确题名在返回候选中优先显示。若外部导入遇到版本冲突，当前 UI 引导手动下载后走本地版本选择流程。

不包含定时追踪、点赞/踩学习、代码质量排序和引用质量筛选。

### 有真实来源的提纲

选择最多 8 篇论文，可先离线整理 Abstract、Introduction、Related Work 和待验证计划，并附库内真实参考文献与证据，下载 Markdown 和固定的科研工作流 Mermaid 示例脚本。

可选择调用 DeepSeek 扩写；取证时补充摘要作为背景，模型输出继续通过有效引用校验。首次真实尝试只返回资料不足，补充摘要与改进任务说明后，复测成功返回 785 字符和 2 条有效证据引用。该结果仍需人核对，不是自动验证全部学术结论。

Mermaid 目前是固定研究流程示例，不能宣传为任意 idea 自动设计专属网络架构；无整篇论文代写或真实实验结果自动生成。

### CSV 图表

上传最多 1 MiB、1000 行 UTF-8 CSV，指定 X/Y 列，生成折线或柱状图、PNG、图注和可复现 Python 脚本。对列名、行列一致性、有限数值和长度做校验；图由固定 Matplotlib 模板生成，不运行上传代码或模型生成代码。

数值由程序计算，图注报告最小值、最大值、均值及点数，明确未进行显著性/因果检验。X 轴按 CSV 行序放置标签，不自动进行数值轴拟合；未实现雷达图、自动统计检验或复杂图形编辑。

## 6. 用户手动验收顺序

1. 上传官方 Transformer v7，再上传 v1；确认新版提示后，先取消，再尝试保留两版。测试替换前先选好要退出当前论文库的目标。
2. 上传扫描版，进入详情点击“识别扫描页 / 继续 OCR”，等真实页数完成，再用扫描版范围提问并检查页码。
3. 打开论文，用章节菜单切换页，缩放原版；从分页文字选段或粘贴本页原文后翻译。
4. 到研究工具页，选择存在引用关系的不同论文，构建图谱并核对引用边原文；同篇的两个版本不会互相连引用边。
5. 选择一篇论文，查看推荐理由；按题名检索公开论文并核对后导入。
6. 填写研究想法，先整理基础提纲和真实参考文献，再尝试模型扩写。
7. 使用 [三行示例 CSV](fixtures/chart_demo.csv)（epoch、accuracy 两列）生成图表；核对值与下载脚本，打开生成 PNG。

## 11. 2026-11-16：独立阅读页与 OCR 排障

### 阅读体验

- “查看”、论文题名和证据跳页改为进入 `/reader/{paper_id}?page=N&from=...` 独立页面，移除侧边抽屉。刷新保留论文与页码，返回链接回到原功能页。
- 原版 PDF 按页展示，默认同时适应容器宽度和高度，完整保留整页版式；可切页、章节跳页、放大和打开原版文件。放大时允许容器内滚动。
- 为工具栏、正文、OCR 状态及翻译区增加留白，桌面原版与文字并排，窄屏上下排列；作者继续最多五位加 etc。
- 扫描件上传成功仅提示文件已保存、需要 OCR，不再把保存文件等同于识别完成。

### OCR 改动与验证边界

- 状态区显示准备引擎、渲染第几页、识别第几页、更新索引、耗时及实际成功页数。当前页识别后立即刷新文字，无需等待整篇结束。
- 网络失败会重新连接，状态未确认时禁止重复启动；记录已删除或认证失效时停止轮询。任务完成时间固定，不继续累加耗时。
- 使用灰度图片降低内存，Tesseract 子进程限制一个 OpenMP 线程，避免小实例线程争抢；保留单篇任务和每页 90 秒超时。针对超时、语言包缺失及进程被终止给出具体提示。
