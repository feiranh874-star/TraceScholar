# 第二阶段结项：本地证据检索与模型回答

更新日期：2026-11-13。

## 已完成

- 新增 `POST /api/research/retrieve`，按研究问题检索全部论文或指定论文。
- 使用本地分词与 TF/IDF 风格评分完成关键词检索，不调用外部模型。
- 每条结果保留论文、文件名、`work_id`、版本、章节、起止页码、原文和相关度。
- 对弱相关的单关键词碰撞设置最低覆盖门槛；证据不足时返回空结果，不用低相关片段充数。
- 兼容第一阶段已导入的旧资料：缺少结构化文本块时，从逐页文本即时构建检索块。
- 中文工作台新增“证据检索”入口、论文范围选择、证据卡片、加载与错误状态。
- 点击证据可以打开论文详情，并定位到对应原始页码。
- 增加离线科研术语桥接：常见中文提问（例如 CLIP 的零样本图像分类）可检索英文论文，并为方法描述提供短语级排序加权。该功能只覆盖已列出的术语，不等于通用翻译；资料不相关时仍返回“当前资料不足”。

## API 契约

请求示例：

```json
{
  "question": "How does CLIP perform zero-shot image classification?",
  "paper_ids": [],
  "limit": 6
}
```

`POST /api/research/retrieve` 只负责本地检索，不调用模型。`POST /api/research/answer` 接收相同请求，先检索再调用配置好的 DeepSeek；无证据时直接返回“当前资料不足”，不会产生模型调用。回答附带本地来源生成的证据记录，模型无法指定任意论文或页码。

前端保留“只检索原文”和“生成证据回答”两个独立操作。回答必须至少包含一条有效 `[E1]` 等引用；非法引用会剔除，完全无有效引用则拒绝展示回答。模型仍可能错误解释真实证据，关键结论须人工核对。

## 验收结果

- CLIP 问题能够从现有论文中检索到原文证据，并跳转至第 6 页等对应页面。
- 完全无关的问题会显示“当前资料不足”。
- 本阶段新增了旧资料兼容、弱关键词误匹配、无证据不调用模型、引用校验、模拟 DeepSeek 请求与异常处理测试。真实调用使用本地已有 CLIP 论文，成功得到带 `[E2]` 引用的回答，并对应论文原文第 6 页。Python 连接的证书链已使用经验证的 CA 证书包修复，未关闭 TLS 校验。
- 中文提问对英文 CLIP 论文的检索和模拟回答测试通过；组委会材料全量回归为 `70 passed`。在本地已有 CLIP 论文上，“CLIP 如何进行零样本图像分类？”的首条证据来自论文第 6 页；宽泛问题“AI的发展”仍返回 0 条证据。
- 对实际演示中“什么是attention”返回 0 条证据的问题，补充了简短中英混合定义问题的检索规则。比赛提供的 `1706.03762v7.pdf` 实测命中第 4 页；仅顺带提及 attention 而没有相关定义词的段落继续被拒绝。云端是否已部署此修复，仍需在 Render 实例做端到端确认。
- 回答提示词要求用自然语言解释数学关系，不输出公式原式；前端再过滤常见 LaTeX 数学块，避免模型偶尔不遵从时直接展示源码。
- 检索结果中的原文片段默认折叠；点击“查看原文片段”才展开，并可继续点击“打开论文”跳到对应页。
- 在组委会材料目录上运行完整回归：`70 passed`；另通过前端 JavaScript 语法检查。自动测试覆盖功能链路，不代表已完成大规模回答质量评测。
