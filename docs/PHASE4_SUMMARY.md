# 第四轮开发总结 跨论文比较与可靠性修复

完成日期：2026-11-15。

本轮完成了 2–5 篇论文的证据检索与比较流程，并修复了真实 DeepSeek 调用中暴露的输出预算、来源归属和失败状态问题。用户已通过部署后的 CLIP/GPT-3 同题截图确认：比较回答正常显示、引用来源默认折叠、原文证据定位到 CLIP 的 zero-shot 方法章节。

本文件记录的是第四轮开发迭代。它不等于最初 1–32 项计划中的“第四阶段：补齐六大模块”全部完成；OCR、翻译、推荐、引用图谱和写作等原计划事项仍需单独验收。

## 一 本轮目标

1. 从单篇证据问答扩展到明确选择多篇论文进行比较。
2. 比较前逐篇取证，比较后校验引用是否覆盖每篇所选论文。
3. 用更多官方材料检验检索与引用流程，区分离线指标和真实模型结果。
4. 根据实际使用反馈修复中英混合问题、回答展示和模型调用失败。

## 二 完成的能力

### 多论文检索与比较

- 新增 `POST /api/research/compare`，可选择 2–5 篇论文。
- 按论文分别检索，再交错排列证据，降低单一来源挤占其他论文的风险。
- 任一所选论文没有有效证据时停止生成；正常比较回答需引用每篇所选论文。
- Agent 入口可以把选定多篇论文的比较问题路由到比较工具，并展示执行步骤。
- 为初始示例论文补充有针对性的中英文术语桥接；它仍是有限规则，不是通用翻译或通用语义理解。

### 回答与引用展示

- 模型被要求用短段落或要点回答，避免表格和公式源码。
- 即使返回 Markdown 表格，前端也会把已识别的表格转换为纵向比较卡片。
- 比较回答限定题目明确要求的维度，默认要求至多三个比较点；这是提示词约束，不是严格字数保证。
- 引用来源默认折叠，展开后保留论文、版本、页码和跳页入口；原文片段也默认折叠。
- 对明显像正文的章节标签做过滤；解析兼容带结尾句点的章节编号，跳过目录页，减少页码误识别。

### 真实模型调用修复

曾为缩短回答把比较输出预算从 4000 降到 2000，却没有控制 `deepseek-flash` 默认的思考模式。同一道题随后再次出现输出达到上限但没有最终回答。修复后：

- 比较输出预算恢复为 4000，最终回答的简洁程度由提示词约束。
- 对 DeepSeek 官方接口的已确认支持模型显式关闭思考模式，不向其他兼容接口盲目添加参数。
- 输出被截断时拒绝展示不完整回答，也不把思考内容当答案。
- 单篇问答和多篇比较在 HTTP 或网络失败后停止加载动画，恢复可重试状态。
- 核对真实回答时发现过一次旧 n-gram 基线被误归为 CLIP；补充方法相关检索词，并提示模型区分论文自身方法与引用的既有工作。

## 三 测试与实际验证

### 离线检索评测

在 Transformer v7、CLIP 和《Understanding Deep Learning》三份材料上建立了 14 道扩展问题，覆盖 6 道 CLIP、6 道教材、2 道跨论文问题。2026-11-15 使用当前代码重新运行离线评测，结果如下。比较答案生成使用模拟模型，不调用付费 API。

| 指标 | 本次复测 | 测量边界 |
| --- | --- | --- |
| 指定论文范围内页码命中@6 | 87.5% | 16 次来源检查 |
| 全库单篇问题页码命中@6 | 75.0% | 12 道单篇问题 |
| 原文证据要点覆盖@6 | 87.5% | 48 组人工标注字符串要点 |
| 比较来源覆盖 | 100% | 2 道比较题，来源存在性检查 |

这些指标不等于最终回答正确率。早期全库命中与要点覆盖分别为 66.7% 和 85.4%；本次复测分别为 75.0% 和 87.5%，不能把小题集上的变化外推为普遍准确率提升。

另对 Transformer v7 的 22 题固定检索集复测：20 道可回答题页码命中@1、页码召回@3 均为 100%；证据字符串要点覆盖@3 为 94.0%，全部要点覆盖的题目比例为 90.0%；2 道不可回答题的误召回率为 0%。这些仍是固定小题集的检索指标。

### 2026-11-15 真实调用验证

复测问题：

> 比较 CLIP 如何进行 zero-shot image classification，以及 GPT-3 如何通过 few-shot examples 学习新任务；说明推理时是否需要更新模型参数，并分别引用原文。

- 用本地两篇论文，在临时论文库通过真实比较 API 调用 DeepSeek，不改变原论文库。
- 修复调用配置后两次请求正常返回；继续修正方法取证与来源归属后，最终代码再次验证成功。
- 最终一次约 1.68 秒，回答 326 字符（含引用），引用覆盖两篇论文，并包含 CLIP 第 6 页分类方法段落。
- 最终响应以 `stop` 正常结束，思考输出长度为 0。
- 用户随后用部署后的相同问题确认回答和折叠引用区正常显示。

这是小样本可用性验证，不代表长期可用率、平均时延或通用事实准确率；本轮未单独确认截图中每个引用按钮的在线跳页行为。

## 四 仍然存在的边界

- 有效引用只能证明引用映射到已有证据，不能保证句子与证据之间的推理正确。
- 当前 Agent 主要是规则路由和固定工具流程，不是自主规划任意科研任务的系统。
- BM25、TF-IDF 稀疏余弦和排名融合已实现；未接入稠密 embedding 或神经重排。
- 多篇不同论文的比较已经可用，但没有专门的跨版本增删差异报告。
- 当前阅读器主要展示分页提取文本，不能等同于完整 PDF 可视化阅读、缩放和证据坐标高亮。
- 扫描页只标记为待 OCR，尚未识别；541 页教材能基础解析，但没有完整异步进度和断点恢复。
- 翻译、相似论文推荐、真实引用图谱、带引用综述工具和 CSV 图表还不能作为已完成模块宣传。
