# 界面精简与收藏夹修复

日期：2026-11-17。当前为本地修改，需提交、推送并等待部署后才能在线验收。

## 本轮完成

1. 视觉识别页面不再显示厂商或具体模型名称；问答页面和错误提示改用通用文案。模型配置与识别结果 JSON 的技术溯源字段保留。
2. 工作台顶部保留搜索，去掉顶部的“导入论文”。
3. 论文库、导入资料、证据检索页面移除顶部重复搜索及导入入口；保留论文库内容区的搜索与导入功能。
4. 导入页处理流程文字增大，桌面两侧卡片自动等高；窄屏上下排列。
5. 证据检索页两张卡片自动等高，不再显示具体模型名称。
6. 检索范围直接显示搜索框，可按题名、作者、文件名或备注搜索；结果按入库时间从新到旧排列。选中论文后显示已选范围，“清除选择”恢复整个论文库检索。
7. 收藏夹内的论文操作改为“移出收藏夹”，使用独立的成员移除接口，仅解除当前收藏夹的关联。PDF、索引、备注、其他收藏夹关联均保留；“全部论文”的永久删除仍有明确确认。

## 部署后测试

1. 在“全部论文”选择一篇 A，通过“整理”同时加入收藏夹 1 和 2。
2. 进入收藏夹 1，点击 A 的“移出收藏夹”。该收藏夹不再显示 A。
3. 检查“全部论文”和收藏夹 2：A 都仍存在；点击查看应能正常打开原文，备注仍在。
4. 刷新页面，重复检查第 3 步；需要时用“添加 / 移出论文”把 A 加回收藏夹 1。
5. 切换工作台、论文库、导入资料和证据检索，核对顶部重复入口已移除。论文库内容区保留正常搜索与导入。
6. 在证据检索的范围搜索框输入论文备注，选中结果，再点“清除选择”，确认显示恢复为检索整个论文库。
7. 在桌面检查导入页、证据检索页两侧卡片底部对齐；窄屏应上下排列。视觉结果页不再显示厂商或具体模型名称。
