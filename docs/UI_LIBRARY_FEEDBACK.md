日期：2026-11-17。当前为本地修改，需提交、推送并等待部署后才能在线验收。

## 本轮完成

1. 视觉识别页面不再显示厂商或具体模型名称；问答页面和错误提示改用通用文案。模型配置与识别结果 JSON 的技术溯源字段保留。
2. 工作台顶部保留搜索，去掉顶部的“导入论文”。
3. 论文库、导入资料、证据检索页面移除顶部重复搜索及导入入口；保留论文库内容区的搜索与导入功能。

5. 证据检索页两张卡片自动等高，不再显示具体模型名称。
6. 检索范围直接显示搜索框，可按题名、作者、文件名或备注搜索；结果按入库时间从新到旧排列。选中论文后显示已选范围，“清除选择”恢复整个论文库检索。
7. 收藏夹内的论文操作改为“移出收藏夹”，使用独立的成员移除接口，仅解除当前收藏夹的关联。PDF、索引、备注、其他收藏夹关联均保留；“全部论文”的永久删除仍有明确确认。

## 部署后测试

3. 检查“全部论文”和收藏夹 2：A 都仍存在；点击查看应能正常打开原文，备注仍在。
4. 刷新页面，重复检查第 3 步；需要时用“添加 / 移出论文”把 A 加回收藏夹 1。
5. 切换工作台、论文库、导入资料和证据检索，核对顶部重复入口已移除。论文库内容区保留正常搜索与导入。
6. 在证据检索的范围搜索框输入论文备注，选中结果，再点“清除选择”，确认显示恢复为检索整个论文库。

## 第二轮反馈：收藏夹直接上传与列表统一

日期：2026-11-17。本轮继续修改，仍需手动提交、推送，等待部署后在线验证。

1. 论文库、导入论文、证据检索和研究工具移除顶部重复标题条。手机保留菜单按钮；工作台保留其搜索入口。
2. “导入资料”统一改为“导入论文”，侧边栏顺序调整为“工作台 → 导入论文 → 论文库 → 证据检索”。
3. 收藏夹内新增“上传论文”：单篇直接导入，多篇进入批量待上传列表。导入页明确显示目标收藏夹，论文同时保存到全部论文，按入库时间从新到旧展示。
4. 同一文件再次上传到另一收藏夹，只增加该收藏夹关联，不重复入库、不修改原备注与入库时间。关联版本仍需确认；保留两版后新记录会进入目标收藏夹。
5. 收藏夹行操作改为“整理 / 查看 / 移出”，三个按钮保持并排；移出仅解除当前收藏夹关联。
6. 工作台“最近导入”复用论文库的列表单元格样式，展示题名、文件、备注、作者、页数、状态和导入时间；列表改为整行宽度，快捷导入放在下方。

### 建议逐步验收

1. 新建一个收藏夹，进入后点击“上传论文”，选一个本机 PDF。检查导入页显示“上传到：你的收藏夹”。
2. 导入完成后检查该收藏夹和“全部论文”：新论文均出现，且排在原有论文之前。
3. 在同一收藏夹上传两篇 PDF，点击“开始批量导入”；处理结束后检查每篇状态与收藏夹内容。
4. 在另一收藏夹上传同一份 PDF：总论文数不增加，两个收藏夹均能看到它，原备注保持。
5. 点击“移出”：当前收藏夹不再显示该论文，全部论文及其他收藏夹仍保留它。
6. 核对侧边栏顺序、页面顶部重复标题已移除；检查工作台最近导入列表与论文库样式一致。
