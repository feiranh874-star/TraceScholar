## 翻译这次重点改了什么

- 单篇：论文库“查看” → 阅读页下方“段落与本页翻译” → “返回原文 ↑”。不再走旧的笼统工作区。
- 多篇：阅读页“多篇批量翻译 ↗”只打开一次，之后直接切换该工具窗口。
- 启动前显示每篇总页数和总工作量，越界输入当场提示。
- 正在翻译时保留原阅读窗口；完成后每篇分别看结果和下载。
