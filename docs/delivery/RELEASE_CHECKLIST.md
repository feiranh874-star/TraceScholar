# 提交前检查

- [ ] 参赛姓名、学校、团队名与报名信息一致。
- [ ] 确认个人中心本届提交截止日期、入口与评分说明。
- [ ] 作品介绍文档包含项目详情与用法、亮点、AI 测试技术落地情况、关键技术、图片、发表/获奖情况、基于其他项目的优化说明；涉及个人经历的事实由作者核对。
- [ ] 用新版 ROADSHOW_SCRIPT.md 录制，检查声音、字幕与最新界面一致；页数、时长、分辨率及格式以本届报名系统最新要求为准，不把历史草稿的固定时长当作已确认规则。
- [ ] 完整作品文件上传到可访问的主流网盘，包含作品文档、源码等；核对链接有效期及提取码。
- [ ] 演示视频上传 B 站、抖音等可公开访问的视频平台，填写对应视频链接；不提交百度网盘视频链接。
- [ ] GitHub 仓库评审可访问，README 身份、架构、启动、评测和已知限制齐全。
- [ ] 手动提交并 Push origin；保存最终 commit。推送后确认 Render 部署的是该 commit。
- [ ] 新工作区 `/workspace`、全部静态脚本在生产镜像可用。
- [ ] 未认证访问首页、阅读页、论文、任务、Agent 历史返回 401；公开 health 返回 200。
- [ ] 两台设备/无痕窗口检查 HTTPS、登录、冷启动、模型回答和原文跳转。
- [ ] 核实免费实例的数据策略；重部署可能清空临时数据，准备可重复导入的公开样例和本地备份。
- [ ] 不在仓库或 PDF/视频中暴露 .env、密钥、密码、验证码；评审凭证用私密渠道提供。
- [ ] 视觉识别已有接口与按页结果展示，逐项核对实际结果，不把识别成功等同于自动验证正确；不宣传全领域新颖性证明。
- [ ] 翻译演示包含页数上限提示、阅读页原地翻译与两篇各翻一页；截图 8 同时包含真实工具执行摘要、最终回答和来源。
- [ ] 如最终提交后禁止修改，冻结对应版本及材料，保留上传回执。

本轮没有自动提交 Git、push、部署或向组委会提交材料。草稿中的占位项不是最终提交信息。
