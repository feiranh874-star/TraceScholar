## 本次新增：批量导入（不调用模型）

1. 左侧点 **「导入资料」**，再点 **「批量导入」**。原来的「单篇导入」仍然保留。
2. 点选文件区域，在 Mac 上按住 Command 选择多个 PDF，或把多个 PDF 一起拖进去。每批最多 **20 个文件、合计 50 MiB**。
3. 检查待上传列表，可以移除选错的文件。需要统一备注时填写「本批论文备注」，例如 **批量测试：待精读**。此时还没有上传。
4. 点 **「开始批量导入」**。先看上传进度，再看逐篇解析进度和每个文件的结果。
5. 建议选一个已入库的 PDF、一个新 PDF 和一个关联旧版一起测：相同文件应显示「已存在，未重复导入」；新论文显示「导入成功」；旧版显示版本提示，等你选择 **「保留两个版本」** 或 **「取消本文件导入」**，不会自动覆盖新版。
6. 完成后点 **「去论文库查看」**，检查新增论文和统一备注。相同文件的原有备注不应被覆盖。
7. 刷新页面后，重新进入「导入资料 → 批量导入」，应能看到刚才的结果；也可展开「最近的批量导入记录」打开历史任务。
8. 某个文件损坏时，应单独显示失败，其余文件继续。修复损坏文件后重新上传该文件即可。任务因临时服务错误或中断而失败时，可点继续处理；已经成功的文件不会重复导入。

本地已实测：四文件混合导入、重复文件跳过、旧版确认保留、无效 PDF 独立报错，以及刷新后恢复结果。离开页面后服务器仍会处理；服务重启能否继续还依赖暂存文件是否仍在磁盘上，免费 Render 的临时磁盘不保证保留。

## 一、先找到 Table 2 的图片（不消耗模型费用）

1. 左侧点「论文库」，保持「全部论文」。找到文件名 **1706.03762v7.pdf**，点它右侧的「查看」。注意不要选 v1。
2. 进入论文阅读页，在左上角页码框输入 **8**，按回车。
3. 在原版页面上方点 **「查看本页表格与图片」**。页面会向下移动，出现「本页表格与图片 · 第 8 页」。等待提取完成。
4. 在 **Table 2** 下方，应看到一张单独的表格截图。再往下是能复制文字的提取表格。
5. 不用理解 BLEU 的计算，只核对这两行有没有抄错：

   | 行名称 | BLEU / EN-DE（英译德） | BLEU / EN-FR（英译法） |
   | --- | --- | --- |
   | Transformer (base model) | 27.3 | 38.1 |
   | Transformer (big) | 28.4 | 41.8 |

6. 表格卡片最下方点 **「下载 CSV（Excel 可打开）」**，浏览器应下载一个 `.csv` 文件。Excel 或 Numbers 打开后也应是这两组数。
7. 点 **「核对整页 · 原始第 8 页」**，应在新页面显示整张 PDF 第 8 页；高亮用于定位表格区域。
8. 阅读页顶部 **「打开原版 PDF」** 会打开浏览器自带的 PDF 阅读器。你 P2 里的黑色工具栏就是这个，属于正常结果；它本身不显示提取表格和 CSV 按钮。部分浏览器可能忽略跳页参数，可以手动输入第 8 页。

说明：BLEU 是翻译效果指标；这里核对数值，是检查系统有没有把表格的行列弄乱。训练成本有合并单元格，展开「合并单元格说明」即可核对，空白不能当成零。扫描图片的结构化表格仍待视觉模型接入。

还想看论文配图：改到第 **3** 页或第 **4** 页，点同一个图表按钮；面板打开后，后续翻页会自动更新。截图点击可在新页面放大。

## 二、给论文写备注，再用备注找它（不消耗模型费用）

已有论文：

1. 「论文库 → 全部论文」，找到一篇论文，点右侧 **「整理」**。
2. 在备注框填写 **老师推荐，待精读**，点「保存」。这句话应显示在论文文件名下方。
3. 在论文库搜索框输入 **待精读**，应找到这篇论文。刷新浏览器后再搜，备注也应保留。
4. 再次点「整理」，修改或清空备注，保存后检查变化。

新导入论文：

1. 左侧点「导入资料」。
2. **先**在「论文备注（可选）」填写备注，**再**选 PDF。选文件会立即开始导入。
3. 遇到版本提示，可以选择「保留两个版本」；备注会随这次导入保存。完全相同的文件不会重复导入，也不会自动覆盖原有备注，需通过「整理」修改。

备注只是你的阅读笔记，可用于找论文；不会被当作论文结论或原文证据。

## 三、试试新的论文选择器（不消耗模型费用）

1. 左侧点 **「证据检索」**。
2. 在问题框下方，点「检索范围」中的论文名称或「全部已入库论文」。
3. 应展开带搜索框的列表，论文按 **最近入库 → 最早入库** 排列，显示文件名、版本、入库时间和备注。
4. 搜索 **待精读**，点击对应论文。列表应收起，选择框显示你刚选的题名和版本。
5. 再点开，换个关键词，不要点击结果，关闭列表：原来的选择应保留。搜索只是筛选列表，不会自动换论文。
6. 需要查全部论文时，点列表顶部「全部已入库论文」。

如果问 CLIP，请先导入并选择 CLIP 论文 **Learning Transferable Visual Models From Natural Language Supervision**。你之前 P3 勾选的是 ZeRO 和 Transformer，它们无法提供 CLIP 运作机制的完整依据，因此显示「资料不足」是合理的。问单篇原理时不用开启多篇比较。

## 四、收藏夹分类（不消耗模型费用）

1. 「论文库」顶部点 **「收藏夹」**，再点 **「＋ 新建收藏夹」**。
2. 输入 **注意力机制**，点「保存」。再建立一个叫 **待精读** 的收藏夹。
3. 在「注意力机制」卡片下点 **「添加 / 移出论文」**，勾选 Transformer v7 和 v1，点「保存」。卡片应显示 **2 篇论文**。
4. 点卡片名称进入，只应显示收纳的论文。点「← 所有收藏夹」返回。
5. 在「待精读」也加入 v7。v7 应同时出现在两个收藏夹里。
6. 返回「全部论文」，v7 仍然只有一条记录，PDF 不会被复制两份。点 v7 的「整理」，能看到两个收藏夹都被勾选。
7. 在某个收藏夹「添加 / 移出论文」中取消勾选一篇并保存：只从该收藏夹移出，全部论文里的原记录应保留。
8. 可以测试「重命名」。测试「删除」时请用临时收藏夹：确认提示会说明只删除分类，论文仍保留。

默认进入论文库显示全部论文；收藏夹是另一种分类视图，同一篇论文可属于多个收藏夹。

## 五、找到版本页码链接和 JSON 下载（不消耗模型费用）

先保证 v7、v1 都在论文库中；版本提示选择「保留两个版本」。

1. 左侧点 **「研究工具」**，再点顶部 **「进入完整研究工作区」**。也可从阅读页点「更多研究工具」。
2. 工作区顶部有一排功能按钮，点 **「版本与管理」**。
3. 在「两个版本的正文差异」中，把「对照版本」选成 **v1**，「比较版本」选成 **v7**。下拉列表可搜索 `1706.03762`，看文件名区分版本。
4. 点 **「生成差异报告」**。等结果出现后，报告顶部应有 **「下载 JSON 报告」**；点击会下载 `version-diff.json`。
5. JSON 是机器能读取的报告文件，不需要你看懂里面的代码；能正常下载即可。
6. 向下看「变化 1」「变化 2」等卡片，直接可见 **「对照版本 · 原始第 X 页」** 和 **「比较版本 · 原始第 X 页」**。点击应打开对应版本的阅读页，并定位到指定页。
7. 点卡片内「展开两侧文字」，再查看文字差异。原始页码链接现在不需要展开也能看到。

正文重新排版也会造成差异，差异数量不代表科学结论改变的数量。选不同论文，例如 ZeRO 与 Transformer，系统应拒绝比较。

## 七、阅读、引用和全文翻译

阅读功能不消耗模型费用；段落翻译和全文翻译会调用模型。

1. 阅读 Transformer v7，第 3 页右侧「本页文字」找到 `[1]` 并点击。页面下方应展开对应参考文献；点「查看参考文献原页」，再点「返回刚才的正文页」。
2. 阅读页文字区选择一小段原文，检查下方「选中的连续原文」。点「翻译段落」后，应显示译文。
3. 全文翻译入口：**研究工具 → 进入完整研究工作区 → 全文翻译**。
4. 顶部「目标论文」选 v7，起始页、结束页都填 **1**，点「启动所选页翻译」。先试一页即可。
5. 点功能栏「后台任务」，等待完成；返回「全文翻译」，顶部原始页码填 1，点「查看目标论文当前页译文」。应有原文和译文。
6. 点「下载已完成的双语 Markdown」，应下载文字文件。阅读页点「中英对照」也可看到已保存译文；尚未翻译的页应说明没有译文。

## 八、其余功能：每个入口在哪

这些可以后测，不需要现在一起完成。

- **批量上传**：主入口为「导入资料 → 批量导入」，操作见本文开头。「完整研究工作区 → 后台任务」中的原入口也保留。
- **纠正题名、作者、摘要**：完整研究工作区 → 版本与管理 →「纠正资料信息」→ 保存信息。刷新后应保留。备注和收藏夹仍在论文库的「整理」中编辑。
- **重新解析**：同一处的「重新解析与索引」→ 后台任务查看进度。任务运行时删除、替换、整理论文会被阻止，等任务完成再操作。
- **旧版归档恢复**：单篇导入时选择替换后，完整研究工作区 → 版本与管理 → 归档记录 →「刷新归档」→ 恢复到论文库。已永久删除的论文不在归档里。
- **公开论文搜索**：完整研究工作区 → 检索与追踪 → 输入英文题名 → 搜索 arXiv → 核对信息后确认导入。需要访问外网。
- **主题追踪**：同页「主题追踪」→ 输入英文关键词 → 添加追踪主题 → 立即检查。可取消；服务休眠期间不会持续检查。
- **推荐和反馈**：同页「本地推荐与反馈」→ 以目标论文推荐 → 点「有帮助」或「不相关」，再次推荐核对反馈效果。
- **引用图谱**：左侧「研究工具」→ 勾选不同论文 →「构建所选论文图谱」。没有真实引用关系时，允许没有连线。
- **综述和 Future Work**：完整研究工作区 → 勾选相关论文 → 图谱与综述 → 填研究主题 → 先「整理图谱与 Future Work 证据」；需要写作时再「生成带引用综述」（调用模型）。
- **研究方向核对**：同页「研究方向逐项核对」→ 输入方向 → 查找核对证据；生成意见会调用模型。本地没找到不等于全球首次。
- **方法架构图**：同页「可编辑研究架构图」→ 填节点和连接 → 生成图脚本 → 检查图示、Mermaid 和 Graphviz 下载。这里只生成设计图。
- **CSV 图表**：左侧「研究工具」→「CSV 图表与图注」→ 选择 `docs/fixtures/chart_demo.csv` → X 填 `epoch`、Y 填 `accuracy` → 生成图表。三维图需要额外填写 Z 数值列。
