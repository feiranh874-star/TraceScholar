# 第六轮统一测试步骤

测试版本：2026-11-16，本地代码。先提交并更新服务，再测试线上版本。新功能入口：工作台「研究工具」→「进入完整研究工作区」。所有页码都是 PDF 的原始页码。先使用合法公开论文，不使用私密资料。视觉模型仍未接入，扫描图片理解和公式转 LaTeX 不列为通过项。

## 1. 图表和细粒度问答

1. 导入 `1706.03762v7.pdf`。目标论文选 v7，页码 8，点击「解析当前页」。
2. 应看到 Table 2 原版截图、结构化表格、核对整页、下载 CSV。检查 base 的两项 BLEU 为 27.3 / 38.1；big 为 28.4 / 41.8。
3. 展开「核对合并单元格」：训练成本合并跨 EN-DE/EN-FR，不应补成两个独立实验数值。空白保留未知，不是零。
4. 问：「Table 2 中 Transformer base 和 big 的 EN-DE、EN-FR BLEU 分别是多少？」回答应带来源，可用表格呈现。正文中出现 41.0、表格中为 41.8 时必须说明差异，不能擅自改原文。
5. 页码 3 / 4 可查看 Figure 1 / Figure 2 与公式候选。截图是原版区域；没有视觉接口时不能宣称理解图内箭头或公式 LaTeX。
6. 细粒度题依次测试：第六位作者及署名/工作机构；Adam beta1/beta2；base GPU 数量/型号/时长；big 英德 BLEU 与旧结果差值；LayerNorm 引用作者/年份。题库在 `backend/tests/evaluation/fine_grained_cases.json`。

## 2. 版本与管理

1. 再导入 v1，选择保留两版。工作区「版本与管理」分别选择 v1 与 v7，生成差异。
2. 应有原文增删/修改、章节变化、原始页码链接和 JSON 下载。相同论文两条记录才能比较；选 GPT-3 与 Transformer 应拒绝。
3. 修改题名/作者/摘要后刷新，检查保存成功；原 PDF 与版本 ID 不改变。
4. 「重新解析与索引」启动任务，去后台任务看进度。正在解析/翻译/OCR 时删除、替换应被阻止。
5. 单篇导入选择替换后，旧版在归档中可恢复。恢复不等于找回已永久删除文件。

## 3. 阅读往返与翻译

1. 从图表「核对整页」打开阅读页，检查区域高亮；翻到下一页后高亮应消失。
2. 第 3 页本页文字中点击 `[1]`，定位 LayerNorm 参考文献；点查看原页 → 第 10 页，再点返回 → 第 3 页。
3. 在文字区选一小段原文，原版中应尝试高亮。原生文字无法匹配或扫描页没有坐标时，核对整页。
4. 工作区「全文翻译」先选 1–1 页启动。任务结束后预览中英文本、下载 Markdown。此按钮会调用已配置 DeepSeek。
5. 阅读页第 1 页打开「中英对照」，应显示已保存译文；勾选联动后滚动左右两栏。联动是按滚动比例，不是逐句语义对齐。
6. 尚未翻译页应明确显示未翻译。原文更新后应要求重译，不能悄悄展示旧缓存。

## 4. 工具 Agent

1. 勾选 v7，提问：「先检查 Transformer 第 8 页 Table 2，再总结 base 和 big 的 EN-DE BLEU 差异。」
2. 应展示实际工具名（如 inspect_page）、状态、带页码回答；base 27.3，big 28.4，相差 1.1。
3. 刷新最近运行记录，应保留本次任务。工具调用总数不超过下拉限制；失败应显示失败，不伪造成功。
4. 比较任务必须取到每篇论文证据并引用每篇；没有证据应显示资料不足。
5. 默认不搜索公网；开启后 arXiv 摘要只是线索，不能直接当作已入库全文来源。

## 5. 批量、恢复和追踪

1. 批量上传 2–3 个 PDF，其中一个是已存在论文的其他版本。可观察逐文件状态；冲突文件不自动覆盖。
2. 选择「保留两个版本」或「取消本文件导入」。成功后刷新资料；清除任务应同时清除暂存文件，不删除已入库论文。
3. 解析/翻译任务中断后，在同一数据目录重启，任务显示 interrupted，可继续已保存页。免费云平台清空磁盘不属于可恢复范围。
4. 「检索与追踪」搜索 Attention Is All You Need，核对后导入。外网失败允许手动下载上传，不应影响本地问答。
5. 添加一个英文主题，立即检查，再取消追踪。定时检查只在服务运行时发生；不是邮件推送。
6. 推荐后点有帮助/不相关；不相关项下次应被排除。演示账号共享反馈。
7. 目标论文代码仓库线索应有原文出处。URL 被提取不代表代码可靠或可以复现。

## 6. 图谱、综述和方向核对

1. 勾选不同论文，在原工作台研究工具生成引用图谱，点击节点与引用证据；工作区可整理中心节点和 Future Work 时间线。
2. 主题输入 attention，先整理证据，再生成带引用综述。PageRank 只属于选定子图；日期取 arXiv 月份，不是首次发表时间。
3. 输入研究方向，核查支持、部分支持、反例与证据不足。不能把本地未检索到当作全球首次。
4. 编辑节点与连接，生成架构图，检查图示、Mermaid、Graphviz 下载与节点一致。生成脚本不代表算法已经实现。

## 7. CSV 和失败场景

1. 用 `docs/fixtures/chart_demo.csv` 生成折线/柱状/散点；三维图需 X/Y/Z 数值列。
2. 雷达需 3–24 个非负分类数据。3D 雷达为角度=类别、半径=Y、高度=Z；必须与研究含义相符。
3. 检查图中的原值、统计、图注和复现脚本；空缺、NaN、无限大或错误列应拒绝而非补零。
4. 用不足资料的问题测试拒答；断开网络测试错误提示与重试；未登录时不得访问工作区、任务和运行历史。
